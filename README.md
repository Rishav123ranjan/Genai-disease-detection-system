# GenAI Based Disease Detection System

## Project Overview

A multimodal GenAI-based clinical decision-support system
that combines medical images, voice symptoms, and patient
vitals with a medical knowledge base.

## Project Objectives

- Medical image analysis
- Voice-based symptom extraction
- Patient vital integration
- RAG-based medical knowledge retrieval
- Explainable AI-generated reports
- Triage decision support

## Technology Stack

- Python
- PyTorch
- FastAPI
- React
- RAG
- Vector Database
- LLM
- Whisper
